聊天指令

/mio ls列出工作流 / 分幕 / 预设（带编号）；/mio ls wf /mio ls sb /mio ls ps 单独列出，/mio ls ch 通道，/mio ls tpl 导出模板
/mio use 1 2 3用第 1 个工作流 + 第 2 个分幕 + 第 3 个预设创建任务并开始；预设可多选 3,4，第 4 个参数可选通道；/mio use 2 只给分幕，其余用默认值
/mio jobs我的任务列表（编号 #）
/mio status [#]查看进度（默认最近一个）
/mio get [#] [html|zip|pdf|img] [模板#]导出并发送成品文件；img 直接发送每幕图片
/mio pause # /mio resume # /mio cancel # /mio rm #暂停 / 继续（或重试失败任务）/ 停止 / 移除记录
/mio ping检查与 Mio 的连接
